# Changelog

## Unreleased
- **One-command install.** `npx github:chsxthwik/ORBIX` installs and starts ORBIX. An installed copy keeps settings and conversations in `%LOCALAPPDATA%\ORBIX`, so they survive updates; a cloned repository still uses its own `data` folder. The package is named `orbix-agent` and ships only the app (90 files, under 0.5 MB). Tests run on GitHub Actions on Windows with Node 20 and 22.
- **Interface polish.** The conversation keeps a readable width when the side panel is open; the panel gets narrower first. Midnight keeps its blue accent. The current item in the sidebar, the side panel tabs and the top bar is marked one way only, with a plain highlight. Steps in one reply sit closer together. Message actions show on hover and under the last message. Text is no smaller than 12 px, inline code included. The send button stays on the right of a narrow message box. Finished setup steps on Home are quieter. Removed the moving line on the session bar, the spinning plus on New session and the lifting send arrow. In Settings, each theme card shows a small drawing of the app in that theme (System shows dark and light side by side) with a check on the one in use. The text size slider is redrawn, its sample sits in a framed box, and the three permission modes sit in one row.
- **ChatGPT provider.** Sign in with ChatGPT and use the models on your ChatGPT plan, with no API key or OpenAI Platform organization. Requests go to the same endpoint the Codex CLI uses in ChatGPT mode and count against the plan's usage limits; when a limit is reached, the message says when it resets. The model list comes from your plan, and the sign-in renews itself. Unofficial: OpenAI can change this endpoint at any time. The OpenAI provider is now API key only.
- **Sign-ins recover by themselves.** When a provider rejects a signed-in token, ORBIX renews the sign-in once and repeats the request; if it cannot be renewed, the message asks you to sign in again instead of blaming an API key.
- **Fewer guesses, faster tools.** The agent cannot overwrite an existing file it has not read in the session. Reading an empty file now counts as reading it. Its instructions now say to ground every claim in what its tools showed, cite the file and line, and say when something is unchecked. Repeated searches without ripgrep reuse unchanged files and run about 3× faster. OpenAI requests carry a prompt cache key, so each step of a session reuses the cached conversation.
- **Sign-ins that finish.** Sign in with xAI now shows a short code to confirm on x.ai, the device sign-in opencode uses, so no local port has to be free and nothing waits on the browser coming back. Sign in with ChatGPT uses exactly the redirect address Codex is registered with (`localhost:1455`) and answers on IPv6 too. If the browser still shows an error page, paste its address into ORBIX to finish. A sign-in that cannot be renewed says why. Renewing a ChatGPT sign-in sends the same scope Codex does.
- **Sturdier sign-ins.** If the sign-in port is busy you are told at once instead of waiting on a page that never loads, and the next port is tried. An xAI sign-in renews itself before it expires; if renewal fails, the provider says the sign-in has expired. Pasting a key replaces a sign-in completely.
- **Waiting animation.** The bar shown while a reply starts is a soft pulse that travels across the line, drawn with the same characters as the ASCII orbit.
- **Visible focus everywhere.** The message box, the sidebar filter and the console line show when they have the keyboard, and the top bar's search button no longer has its ring cut off.
- **One size scale for controls.** Buttons are 36 px, small buttons 30 px, sidebar and Settings rows 34 px, and filters and pins 28 px, each with one corner radius. Opening a tool step no longer makes its row jump. Transitions use the shared timing and easing.
- **Clean-up.** Removed about 450 lines of styles nothing used or that later rules always replaced, an unused script, the unused `GET /api/git/log` route and a stale event. `--no-window` is now `--no-open` (the old name still works). Sign-in callback servers close when ORBIX stops and no longer crash the process on a late error. The README says Windows, which is where ORBIX runs.
- **Bigger tab close button** (24 px), and in a narrow window the session bar keeps the conversation's name readable instead of shrinking it to one letter.
- **Allow edits, ask before commands.** A third permission mode between Ask me first and Allow everything: file edits run without asking (each can be undone) and commands still wait for you. Home shows it as Edits allowed.
- **Trusted commands.** When a command asks for approval you can choose Always allow this command, and Settings → Permissions lists, adds and removes them. `npm run *` covers any script. A command that chains, pipes, redirects or substitutes (`&&`, `;`, `|`, `>`, `$(`) always asks, even if it starts with a trusted one. PowerShell commands are never trusted automatically.
- **Instructions for every project.** Settings → Instructions holds what the agent should always know about you and how you work. It is sent in every session before the project's own AGENTS.md or CLAUDE.md, which wins when the two disagree. Stored as `data/AGENTS.md`.
- **New website.** One page with no script: what ORBIX is, the install commands, real screenshots, the feature list as text, the 17 providers, safety, questions and how to start. The count-up numbers, the scrolling terminal and the simulated demo are gone. It uses IBM Plex Sans and JetBrains Mono like the app.
- **Simpler Home.** One column: the ASCII planet, the task box, the folder it runs in, four suggestions, then your sessions beside your projects. Build and Plan are one switch next to Start. The WORKSPACE label, status line, action toolbar, Compact and Motion toggles, starter cards, constraint chips and draft footer are gone; density stays in Settings → Appearance. The session search icon no longer overlaps its text, and the sidebar section label is in sentence case.
- **Web-only app.** ORBIX now starts as an authenticated local web app in your default browser. The native Windows shell and its build, install, and packaging paths have been removed; existing chats, settings, and provider data remain in `data/`.
- **Session bar.** Every conversation has a bar on top with its state (Ready, Working with a timer, Needs your OK), its name (click to rename), and how many messages and steps it has.
- **Find in conversation.** Ctrl+F highlights every match and steps through them with Enter and Shift+Enter.
- **Your messages.** Ctrl+Shift+O lists the messages you sent and jumps to the one you pick.
- **Focus mode.** Ctrl+Shift+F hides the sidebar, tabs, side panel and status bar so only the conversation is left.
- **Wide reading column.** A button in the session bar widens the conversation for long diffs and tables.
- **Calmer Home.** Four task suggestions under the task box as plain buttons. The greeting, the animated headline, the typing placeholder, the resume card and the activity map are gone; Recent and This week already show the same things.
- **New interface font.** IBM Plex Sans (with italics) replaces Inter; JetBrains Mono stays for code, paths and commands.
- **Ask about a selection.** Select text in a conversation and a small bar offers Ask about this, which puts it in the message box as a quote, or Copy.
- **Where you are in a long reply.** Once your message scrolls out of sight, the session bar shows it; click it to jump back.
- **Keys.** Ctrl+= and Ctrl+- change the conversation text size (Ctrl+0 resets). Ctrl+Tab and Ctrl+Shift+Tab move between open sessions.
- **See what the agent is doing.** Under the message box, the step in progress (Reading src/auth.js, Running npm test, Thinking, Writing the reply) with its own timer. The window title shows Working or Needs your OK, so the taskbar does too, and the finish notification says how long it worked.
- **Sidebar.** Running sessions show their current step and time. Pin conversations to a Pinned section at the top. Each conversation has a menu (the ⋯ button or a right-click) to open, pin, rename, start a new session in its project, show the folder or delete. In the filter, Enter opens the first match and the arrow keys move through the list.
- **Settings.** Overview is now one page that shows how everything is set: providers and their model counts, the default, fast and plan models, permissions, where commands run, web search, MCP servers, and your conversations, projects and pins. Each line opens its page. Appearance adds Density (Comfortable or Compact) and the reading column width. Shortcuts has its own page with a filter.
- **Safer edits.** An edit whose text matches only when whitespace is ignored is applied only to a file the agent has read in this session and that has not changed since; otherwise it is asked to read the file and quote it exactly.
- **Steadier sidebar and tabs.** They are rebuilt only when what they show changes, not on every status event, so hover, keyboard focus and an open row menu stay put while agents work. A new conversation not yet in the list says "new" instead of "now".
- **Timers survive a reload.** Working times in the session bar, status bar and sidebar come from the agent's own turn start, so reloading the window no longer resets them to 0.
- **Quieter interface.** Flat primary buttons without glow, no light behind the page, live dots that stay still, no running light on the session bar or the task box, no hover lifts or sliding arrows, and section labels in sentence case.
- **New first screen.** Before a model is connected, Home is one screen: the providers as a short list on the left, each marked API key, Sign in or No key, and an example session on the right. The six-item feature list is gone.
- **Cleaner mark.** The ring is one continuous line around the planet with an even gap, and the orbit and node are lighter at large sizes.
- **Sharper ASCII orbit.** The planet has a soft edge, dithered shading and a highlight, the ring is drawn as one line that passes in front of the planet, and the picture resolves out of noise when it appears.
- **Sign in with xAI.** Open the xAI provider in Settings and sign in with your Grok account. Uses the Grok CLI's public client registration (unofficial; xAI can revoke it).

## 3.1.0
- **New themes and controls.** Midnight (cool dark) and Frost (cool light) join Dark and Light, with support for Windows high-contrast mode and the system's more-contrast setting. Buttons have clearer hover, pressed and disabled states, and the focus ring now follows each control's shape.
- **Steadier ASCII orbit.** Even frame pacing, no squashing in narrow windows, and it stops cleanly when removed.
- **README rewritten** with new logos, current screenshots of every theme, a provider grid and an architecture diagram.
- **New Home.** One question and the task box first, with project, model, Plan first and approvals in its bottom row. Sessions that need you or are working show above it. Recent conversations, projects and this week follow, and the screen fits without scrolling on a normal window. The planet stage, big numbers and activity grid are gone.
- **New mark and ASCII touches.** A cleaner solid logo that stays sharp at small sizes, and a new app icon. The node on the sidebar mark travels its orbit while the agent works. An ASCII orbit greets you on Home and reacts to your pointer and to what the agent is doing. The headline decodes into place, the task box types example tasks, spinners and the working indicator are ASCII, and empty panels have small art.
- **Real provider logos.** Providers now show their own marks on Home, in Settings, in the model picker and on the model button.
- **Calmer workspace.** Sidebar has Home and Search rows. Side panel tabs show words. One tab style, sentence-case labels, and no animated background behind conversations.
- **New Settings.** A larger sheet with a search box that jumps to any setting. Overview shows your setup at a glance; Providers is a short list where one row opens at a time; Models has its own page; Permissions uses clear choices, and Allow everything now asks you to confirm; Appearance shows theme previews.
- **OMP CLI support removed.** ORBIX now runs only its own agent. Gone: OMP detection, the engine switch on Home, the OMP CLI settings tab and sign-in, Fast mode, `/handoff`, and listing or deleting OMP's own conversations (they stay in `~/.omp`, untouched). Old `ompPath`, `launch` and `defaultEngine` settings are dropped on load. Project folders `.omp/AGENTS.md`, `.omp/skills` and `.omp/commands` are still read. On first run ORBIX now picks the first WSL distribution that starts, else Windows.
- **New look.** Graphite surfaces with a lime accent in Dark and Light.
- **Sidebar.** A Running section lists sessions that are working or need you. A new conversation shows under its project right away instead of "No conversations yet".
- **Session view.** Consecutive tool steps of one reply sit evenly instead of with large gaps. A reply summary lists what the agent read, searched, ran and changed. 1 and 2 answer an approval from anywhere outside a text field.
- **Fixes.** A tool's run time no longer includes the time it waited for your approval. Tabs shrink before the tab strip scrolls. "1 model" instead of "1 models". The status bar shows "WSL" instead of "WSL · ?" for the default distribution. Undo buttons share one icon.
- **Install.** `tools/install.ps1` installs ORBIX to `%LOCALAPPDATA%\Programs\ORBIX` with shortcuts and an Apps entry; `Uninstall-ORBIX.ps1` removes it and keeps your chat history. `Create-Shortcuts.cmd` is gone.

## 3.0.0
- **ORBIX - Unified ADE**: a native Windows app where an AI agent works on your project. It reads files, edits them and runs commands, and asks before it changes anything. Every file change can be undone.
- **Its own agent**: 17 providers (Anthropic, OpenAI, Google Gemini, xAI, Groq, Mistral, DeepSeek, OpenRouter, Together, Fireworks, Cerebras, Moonshot, Z.ai, Qwen, Ollama, LM Studio, any OpenAI-compatible server), Sign in with OpenRouter, live model lists, prices and context sizes, thinking levels, automatic retries, cost and context display.
- **Agent tools**: read, write, edit, bash (PowerShell on Windows), glob, grep, web fetch, helper agents, task list, MCP servers, skills, custom slash commands, `@file` mentions, images and text attachments, `/compact`, `/plan`, `/model`, `/cost`, `/undo`, retry and HTML export.
- **Model roles**: choose a fast model (chat titles, summaries, helper agents) and a plan model (`/plan`) in Settings → AI providers → Models, or per session with `/model fast|plan <model>`. Titles never use the main model.
- **Hooks**: your own commands before and after tool calls, on each message and when the agent stops (`data/hooks.json`, or `.orbix/hooks.json` in a project, which asks once before it runs). Exit code 2 blocks the action and tells the agent why. Listed in Settings → Tools & MCP and with `/hooks`.
- **Branching**: branch a conversation from any message of yours (or `/branch`). It opens in a new tab with everything before that message; your files are not changed.
- **Web search**: the `web_search` tool, off until you add Brave Search, Tavily or your own SearXNG in Settings → Tools & MCP. Needs no approval once on; the key is stored encrypted.
- **Project memory and goals**: `/init` writes or refreshes AGENTS.md, `/memory` shows where it is, and `/goal <text>` keeps the agent working by itself (up to 6 rounds, Esc stops it) until it ends with GOAL_DONE.
- **Interface**: animated home, inline approvals above the message box (1 allow once, 2 allow for the session, Esc deny), `/` and `@` pop-ups, coloured command output, diffs, tabs, side panels (files, git, plan, agents, console), command palette (Ctrl+K), light and dark themes, measured status bar.
- **Nothing to install**: the release zip includes its own Node.js (checksum verified).
- **Safe by default**: local server on `127.0.0.1` with a per-launch token, strict Content-Security-Policy, keys encrypted with Windows DPAPI, private-network protection in web fetch, MCP project servers need your approval.
- **Optional**: if the OMP CLI is installed, sessions can also run with it.
